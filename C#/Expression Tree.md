لامبدا اکسپرشن دو هدف رو بر اورده میکند یعنی هر جا که Func یا delegate داشته باشیم این لامبدا اکسپرشن میتونه جا اون بشینه تا مادامی که اون signature رو رعایت بکنه.
دومین قابلیت تبدیل لامبدا را تبدیل کنیم به یک Expression tree.

lambda expression on IEnumerable and IQueryable 

زمانی که یک Where روی یک IEnumerable زده میشود محتویات اون Predicate  یک delegate هست ولی زمانی که روی IQueryable یک where صدا میزنیم محتوایات اون یک Expression<func< هست.

چون IEnumerable یک کالکشن inmemory  یا InSource هست و محتویات و ساختار اون مشخص هست. پس کافیه یک delegate بگیریم و اون تبدیل کنیم به IL. که به اصطلاح به اون linq to object هم میگیم.

زمانی که با IQueryable کار میکنیم data اون خارج از فهم ارتباط کامپایلر هست چون ممکن هست Sql - Xml - file یا فایل خارجی هست. و نمیتوان Expression را مستقیم تبدیل به IL کنیم. چون نمیداند که با چه ادبیاتی به Source متصل بشه.
پس داخل Where یک Expression میگیریم و در زمان کامپایل اون رو تبدیل میکنیم به Expression tree حالا کسی که میخواهد از اون استفاده کنه مثلا EF core اون درخت را پارس میکند و تبدیل به مثلا TSQL  میکند.
حالا یک کتابخانه دیگه این درخت رو تبدیل میکنه به زبانی که میتوان با اکسل یا هرچیزی کار کرد.
و اون کتابخانه اون زبان مثلا TSql رو میفرسته سمت mssql .

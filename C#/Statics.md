زمانی نوع کلاس را static  میگذاریم که تمام موارد داخل کلاس static باشد. این کلاس نمیتواند نمونه سازی شود. 
و میتوان بدون نمونه سازی از متدهای آن استفاده کرد.
و تنها وظیفه آن بسته بندی متد ها و متغییر های مشابه هستند.

![[Pasted image 20240117200155.png]]

نحوه ذخیره استتیک ها در مموری :

متد هایی داخل یک کلاس زمان صدا زدن به اصطلاح instance Method هستند و متد های استتیک Class method هستند.

Class method ها در حافظه HFH هیپ ذخیره میشوند که حافظه مشترکی در برنامه هست.
اما Instance method ها زمانی که یک نمونه از کلاس ساخته میشود یک متد هم در هیپ ساخته میشوند که ماهیت متفاوتی دارند.

Class method ها Thread safe نیستند.
زمانی که میخواهیم بین تمام منابع یک متد را فراخوانی کنیم از آن استفاده میکنیم.

# Redis: کش در حافظه و ساختار داده

## 1. Interview Relevance Summary

**Redis** یه **کش در حافظه (in-memory)** با سرعت بالاست که علاوه بر key-value ساده، **ساختار داده‌های مختلف** (رشته، هش، مجموعه، لیست، مجموعهٔ مرتب) رو پشتیبانی می‌کنه و برای سیستم‌های **توزیع‌شده** هم به‌کار می‌ره. تو مصاحبهٔ Backend معمولاً می‌پرسن Redis برای چیه، چه زمانی به‌جای دیتابیس اصلی استفاده می‌شه، و با ساختارهایش (مثلاً برای کاهش بار دیتابیس یا صف ساده) آشنا باشی. برای انتخاب نوع دیتابیس و cache به **[[Database]]** مراجعه کن.

---

## 2. Redis چیه؟

کش **کوتاه‌مدت** و **محدود** در **حافظه (RAM)** با **سرعت بالا**. هدفش اینه کارهایی که **منبع و زمان زیاد** می‌خوان (مثلاً کوئری به دیتابیس اصلی) رو کمتر کنیم و پاسخ رو سریع‌تر بدیم. علاوه بر کش، Redis یه ابزار قدرتمند برای **سیستم‌های توزیع‌شده** است (قفل توزیع‌شده، صف، pub/sub و غیره). می‌تونی طوری تنظیمش کنی که داده رو روی **دیسک** هم persist کنه.

Redis روی **یک هستهٔ CPU** کار می‌کنه و دستورات به‌صورت **اتمیک** اجرا می‌شن؛ پس برای عملیات ساده روی یک کلید نگران race condition بین دستورات نباشی (البته تراکنش چندکلیدی جدا است).

## 3. ساختارهای داده و دستورات متداول

### String و عملیات اتمیک

Redis توابع زیادی برای کار با **رشته** داره. چون تک‌هسته و اتمیکه، برای سناریوهایی مثل **کاهش موجودی با همزمانی بالا** مناسب است. مثال: ۱۰ عدد موجودی، ۱۰۰۰۰ کاربر همزمان می‌خوان بخَرن — با **INCRBY quantity -1** و چک کردن مقدار `> 0` می‌شه مطمئن شد فقط ۱۰ نفر اول موفق می‌شن.

- **SET / GET**: تنظیم و خواندن مقدار.
- **GETSET**: مقدار قدیمی رو برمی‌گردونه و مقدار جدید رو تنظیم می‌کنه (برای الگوی قفل ساده یا فلگ مفیده).
- **INCRBY**: افزایش/کاهش عددی به‌صورت اتمیک.
- **MGET / MSET**: چند کلید رو در **یک درخواست** بخون یا بنویس تا به‌جای N بار رفت‌وآمد، یک بار تبادل کنی و فشار و تأخیر کم بشه.

**Global Lock**: با **GETSET** (یا SET NX) می‌شه وضعیت دسترسی به یه منبع مشترک رو بین چند درخواست همزمان کنترل کرد (مثلاً فقط یکی وارد یه بخش خاص بشه).

### Hash (HSET / HGET)

به‌جای چند کلید جدا برای فیلدهای یک «شیء»، می‌تونی یه **کلید** (مثلاً `page20`) و چند **فیلد–مقدار** داشته باشی:

- **HSET** برای تنظیم فیلدها تحت یک نام.
- **HGETALL** برای گرفتن همهٔ فیلدها.
- **HGET / HMGET** برای یک یا چند فیلد.

### Set (مجموعه)

برای **مجموعه‌ها** (اعضا یکتا):

- **SADD**: اضافه کردن عضو.
- **SISMEMBER**: آیا عضو داخل مجموعه است؟
- **SINTER**: اشتراک دو مجموعه.
- **SUNION**: اجتماع دو مجموعه.

### List (لیست)

برای **صف** یا **لیست مرتب**. در پروژه‌های کوچک می‌تونی به‌جای RabbitMQ یا Kafka از لیست Redis برای صف ساده استفاده کنی.

- **LPUSH / RPUSH**: اضافه از چپ یا راست.
- **LRANGE**: خواندن بازهٔ ایندکس (مثلاً `LRANGE mylist 0 -1` یعنی از اول تا آخر؛ `-1` = آخر).
- **LPOP / RPOP**: خارج کردن از چپ یا راست.
- **BLPOP / BRPOP**: منتظر موندن تا آیتم بیاد (blocking) — برای الگوی producer/consumer؛ سرویس‌های مختلف می‌تونن روی همون لیست push/pop کنن و کارها به‌صورت async بین سرویس‌ها تقسیم بشه.

### Sorted Set

همان **Set** با **امتیاز (Score)** برای هر عضو؛ Redis بر اساس امتیاز مرتب نگه می‌داره. مصداق بارز: **لیدربورد (Leaderboard)** بازی یا رتبه‌بندی.

- **ZADD**: اضافه با امتیاز (مثلاً `ZADD x 1 ali 2 reza 2.2 saeed`).
- **ZRANGE / ZREVRANGE**: بازهٔ مرتب‌شده از کم به زیاد یا زیاد به کم؛ با **WITHSCORES** امتیاز هم برمی‌گرده.
- **ZRANK**: رتبهٔ عضو در مجموعهٔ مرتب (از صفر).

## 4. Key Interview Talking Points

- **Redis**: کش in-memory با سرعت بالا؛ ساختار دادهٔ متنوع (string, hash, set, list, sorted set)؛ تک‌هسته و اتمیک برای هر دستور؛ قابلیت persist روی دیسک.
- **کی استفاده می‌شه**: کاهش بار دیتابیس، جواب سریع، قفل یا شمارندهٔ اتمیک، صف ساده، لیدربورد و رتبه‌بندی.
- **String**: INCRBY و GETSET برای موجودی و قفل ساده؛ MGET/MSET برای کم کردن تعداد درخواست.
- **List + BLPOP**: صف ساده و تقسیم کار بین سرویس‌ها (جایگزین سبک برای message queue).
- **Sorted Set**: لیدربورد و هر جایی که به ترتیب بر اساس امتیاز نیاز داری.

---

## 5. When to Use / When NOT to Use

- **استفاده**: کش برای دادهٔ داغ، کاهش خواندن از دیتابیس، قفل/شمارندهٔ اتمیک، صف سبک، لیدربورد.
- **عدم استفاده**: به‌عنوان **تنها** منبع حقیقت برای دادهٔ بحرانی و پایدار (با ریسک از دست رفتن با ریست یا بدون persistence مناسب)؛ برای دادهٔ خیلی بزرگ که در حافظه جا نمی‌گیره.

ردیس چیست؟
کش حافظه کوتاه مدت و محدودی هست که سرعت بالایی دارد.
کاری که ریسورس زیاد و زمان زیادی میخواد را جلو گیری میکنیم.
کش in memory هست.
اما ردیس یک ابزار قدرتمند برای سیستم های distributed هست.
ردیس به ما امکان ثبت دیتا با دیتا استراکچر های مختلف میدهد.
امکان این رو مدهد که دیتای داخل خودش در فایلی ثبت شود.
ردیس از یک هسته کور استفاده میکند. باعث اتومیستی هست.Atomisity

ساختمان داده :
string and global lock :
ردیس فانکشن هایی بسیار کارآمد برای کار با string ها در اختیار ما میگذارد که با توجه به اینکه روی تک هسته cpu کار میکند در موقعیت هایی واقعا کارآمد و مفید هست.
برای مثلا ما 10 عدد موجودی از یک کالا در انبار داریم حالا 10000 کاربر به صورت همزمان به سمت سرور برای خرید این محصول درخواست میزنند.
ما با استفاده از INCRBY -1 و یک شرط >0 میتوانیم کنترل کنیم که فقط ده نفر خوش شانسی که سریع تر سفارش را ثبت کردن صاحب اون محصول باشن.

دستور Get and set and getset and ...

set name "Ali"
get name
set quantity 5
INCRBY quantity -1
getset : مقدار قدیمی را به ما میدهد و مقدار جدید را تنظیم میکند.
GlobalLock : از GetSet برای تغییر وضعیت و سطح دسترسی در دو درخواست همزمان برای ورود به یک صفحه خاص که به این عمل globalLock میگویند.

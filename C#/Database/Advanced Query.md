زبان Declarative زبانی هست که صرفا میگوییم چه میخواهیم مهم نیست انجین چیکار میکند.
Imperative مانند ado.net که کانکشن ایجاد میشود کوئری نوشته شده و ارسال میشود.
Declarative ها مانند تاکسی هست که به او مقصد را میگوییم و بسته به شرایط خواسته ما را اجرا میکند.
چرخه عمر کوئری زمانی که کاربر یک درخواست به sql server میفرستیم ابتدا گرامر چک میشود بعد متغیر ها و بعد وجود دیتابیس را چک میکند و بعد انجین اس کیو ال نتایج را ظاهر میکند

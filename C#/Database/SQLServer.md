دیتابیس به صورت کنسول روی سیستم کاربر نصب شده و سپس با نصب sql server management میتوان کنترل ویژوال روی محتوا و تنظیمات دیتابیس دارد.

 یک دیتابیس جدید ساخته میشود به صورت دیفالت دارای چندین پوشه شامل database diagram است که میتوان از دیتابیس و جدول های داخل آن یک دیاگرام ایجاد کرد.
 پوشه table شامل جداول پروژه میباشند.
 تیک AlowNull برای ایجاد قانون درج دیتای خالی یا غیر خالی (اجباری یا اختیاری) 
 در ایجاد جدول تایپ های مختلف هر فیلد را باید مشخص کنیم.
 big int
 int 
 char شامل فضای خالی
 nchar شامل فضای خالی برای یونیکد های مختلف
 varchar به اندازه طول استرینگ 
 nvarchar به اندازه طول استرینگ با یونیکد های مختلف
 binary شامل اعداد باینری
 bit شامل دو حالت 0,1 میباشد به عنوان boolean
 image برای ذخیره سازی انواع فایل ها
 dateTime بر اساس گرینویچ
 dateTimeOfset اختلاف گرنویچ با مبدا

کلاس ابسترک هم میتواند متد را تعریف و هم میتواند پیاده سازی کند.
ولی در اینترفیس فقط میتوان متد هارا تعریف کنیم.
البته بعد از نسخه 8 میتوان در انیترفیس یک خروجی دیفالت برای متد قرار داد.
در زمانی که در حال اضافه کردن یک فیچر برای یک پکیج هستیم میتوانیم از این قابلیت استفاده کنیم و با up casting از ان بهره ببریم :
![[Pasted image 20240222182938.png]]
abstract میتواند شامل مواردی باشند که در کلاس های دیگر هم هستند.
ولی Interface ها فقط شامل undefined methods only هستند.
Abstract ها از multiple inheritance  پشتیبانی نمکینند.
اما interface میکند.

چه زمانی استفاده کنیم؟
Abstract زمانی که اطمینان داریم لازم نیست تا کلاس های فرزند متد هارو خودشون پیاده سازی کنن. چرا که پدر خودش شامل پیاده سازی هست.
ولی در interface باید متدها پیاده سازی شوند.
اینترفیس از این نظر بهتر هست چرا که انعطاف پذیری بیشتری به ما میدهد. و مفاهیم را به اجبار باید پیاده سازی کنند.

interface کانستراکتور ندارد.
از کلاس ابسترکت و اینترفیس نمیتوان نمونه ایجاد کرد.

params: 
	برای مثال متد :
	public static int add(params int[] listNumbers)
	 که میتوان به صورت زیر فراخوانی شود.
	 add(12,13,14,15,16,...) 
	 یعنی این تابع به تعداد نامشخصی ورودی از اعداد int دارد که میتوان به آن پاس داد.
	 زمانی استفاده میشود که نمیدانیم چند ورودی داریم.

out- ref:
	با استفاده از این دو کلمه کلیدی میتوان به متدهایی که داریم رفرنس پارامتر پاس دهیم.
	تفاوت out و ref در این هست که  برای out میتوان متغیری استفاده کنیم که مقدار اولیه ندارد. و بعد از پاس دادن به متد باید مقدار دهی شود.
	برای ref حتما باید متغیر مقدار داشته باشد و میتوان پس از ارسال به متد مقدار دهی نشود.

نکته : در حالت عادی بدون استفاده از out و ref مقادیر پاس داده شده به متد از طریف value ارسال میشوند. و برای هر متغیر پاس داده شده در متد یک کپی از متغیر در حافظه ایجاد میشود و داخل تابع از کپی آن استفاده میشود.

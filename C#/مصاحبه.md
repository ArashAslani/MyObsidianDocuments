# راهنمای آمادگی مصاحبه Backend Developer

این فایل یک چک‌لیست جامع از موضوعات مهم برای مصاحبه‌های Backend Developer است. هر بخش را به صورت کامل مطالعه کنید و آماده باشید تا در مصاحبه درباره آن‌ها صحبت کنید.

---

## 1. ساختارهای داده (Data Structures)

### HashSet
- **تعریف**: مجموعه‌ای از عناصر یکتا بدون ترتیب
- **مزایا**: O(1) برای Add، Remove، Contains
- **کاربردها**: حذف Duplicate، بررسی وجود عنصر
- **نکات مصاحبه**: تفاوت با List، Dictionary، و SortedSet

### Array
- **تعریف**: ساختار داده خطی با Index
- **مزایا**: دسترسی O(1) با Index
- **معایب**: Insert/Delete O(n)
- **نکات مصاحبه**: Array vs List، Dynamic Arrays

### String
- **تعریف**: دنباله‌ای از کاراکترها
- **مزایا**: Immutable در .NET
- **نکات مصاحبه**: String vs StringBuilder، String Interning، Memory Management

### Tree
- **تعریف**: ساختار داده سلسله‌مراتبی
- **انواع**: Binary Tree، BST، AVL، Red-Black
- **نکات مصاحبه**: Traversal (In-order، Pre-order، Post-order)، Balance

### Graph
- **تعریف**: مجموعه Node‌ها و Edge‌ها
- **انواع**: Directed/Undirected، Weighted/Unweighted
- **الگوریتم‌ها**: BFS، DFS، Dijkstra، A*
- **نکات مصاحبه**: Representation (Adjacency List vs Matrix)

---

## 2. الگوریتم‌ها (Algorithms)

### Hashing
- **تعریف**: تبدیل داده به مقدار Hash
- **کاربردها**: Hash Tables، Distributed Hashing، Consistent Hashing
- **نکات مصاحبه**: Collision Resolution (Chaining، Open Addressing)، Hash Functions

### Reversion (احتمالاً Reversal)
- **الگوریتم‌های معکوس**: Reverse String، Reverse Linked List
- **نکات مصاحبه**: Iterative vs Recursive Approaches

### Concurrency
- **تعریف**: اجرای همزمان چند Task
- **مفاهیم**: Threading، Async/Await، Parallel Programming
- **نکات مصاحبه**: Deadlock، Race Condition، Lock Mechanisms

---

## 3. System Design

### Sharding
- **تعریف**: تقسیم داده بین چند Database
- **استراتژی‌ها**: Range-based، Hash-based، Directory-based
- **چالش‌ها**: Rebalancing، Cross-shard Queries
- **نکات مصاحبه**: Trade-off بین Sharding و Replication

### Kibana
- **تعریف**: Visualization Tool برای Elasticsearch
- **کاربردها**: Log Analysis، Monitoring، Dashboard
- **نکات مصاحبه**: ELK Stack (Elasticsearch، Logstash، Kibana)

### RabbitMQ
- **تعریف**: Message Broker برای Async Communication
- **مفاهیم**: Queues، Exchanges، Routing
- **نکات مصاحبه**: Pub/Sub Pattern، Message Durability، Dead Letter Queue

---

## 4. Network & Performance

### RTT (Round Trip Time)
- **تعریف**: زمان رفت و برگشت یک Packet
- **عوامل مؤثر**: Distance، Network Congestion، Protocol Overhead
- **نکات مصاحبه**: Latency vs Throughput، CDN، Caching Strategies

---

## 5. Database & API Design

### Database Schema Design
- **مفاهیم**: Normalization، Denormalization، Indexing
- **نکات مصاحبه**: Trade-off بین Normalized و Denormalized Schema، Query Optimization

### API Schema
- **مفاهیم**: RESTful Design، GraphQL، API Versioning
- **نکات مصاحبه**: HTTP Methods، Status Codes، Pagination، Filtering

---

## 6. اصول کدنویسی (Coding Principles)

### Clean Code
- **اصول**: Readability، Maintainability، Simplicity
- **نکات مصاحبه**: Naming Conventions، Function Size، Comments

### OOP (Object-Oriented Programming)
- **مفاهیم**: Encapsulation، Inheritance، Polymorphism، Abstraction
- **نکات مصاحبه**: Design Patterns، Composition vs Inheritance

### SOLID Principles
- **S**: Single Responsibility Principle
- **O**: Open/Closed Principle
- **L**: Liskov Substitution Principle
- **I**: Interface Segregation Principle
- **D**: Dependency Inversion Principle
- **نکات مصاحبه**: مثال‌های عملی از هر Principle

### System Design (SD)
- **اهمیت**: در مصاحبه‌های Senior، System Design از Coding مهم‌تر است
- **مفاهیم**: Scalability، Availability، Consistency، Partition Tolerance (CAP Theorem)
- **نکات مصاحبه**: طراحی سیستم‌های Distributed، Load Balancing، Caching Strategies

### Testing
- **انواع**: Unit Tests، Integration Tests، E2E Tests
- **مفاهیم**: Test-Driven Development (TDD)، Mocking، Test Coverage
- **نکات مصاحبه**: چه چیزی را Test کنیم؟ Trade-off بین Coverage و Maintainability


زبان های برنامه نویسی از نظر مدیریت حافظه به دو دسته زیر تقیسم میشوند:
1. Unmanaged : در این دسته از زبان ها، وظیفه ایجاد اشیا، تشخیص زمان درست برای از بین بردن آنها برعهده برنامه نویس هست. مثل C و C++
2. Managed : این دسته از زبان ها، ایجاد اشیاه مانند قبل دست برنامه نویس هست. اما وظیفه تشخیص و از بین بردن آنها در زمان درست را (Clr) Runtime بر عهده میگیرد. مانند : Java و C#
ایده اصلی زبان های Managed این است که درگیر مباحث Memory Management نشویم و تمرکز اصلی روی Business زبان باشد.

درگیر شدن با Memory management در اکثر مواقع در پروژه های بزرگ باعث میشود که نگهداری از نرم افزار کار دشواری شود و پروژه به تدریج Legacy شوند.

![[Pasted image 20230918200312.png]]

قدر زبان های Unmanaged در Game Engine ها و Real-Time Processing ها دیده میشود که تماما مدیریت حافظه بر عهده برنامه نویس هست تا برنامه دچار اختلال یا کندی سیستم حتی در حد چند میلی ثانیه نشود.

در زبان های Managed مباحث جانبی مدیریت حافظه به وسیله Runtime (Clr)به صورت خودکار انجام میشود. گاهی باید قسمت های حساس برنامه به اصطلاح (Hot-Path) های خود را پیدا کنیم و از این قسمت ها Benchmark بگیریم تا برنامه تو حجم بالای درخواست و بار دچار نشتی حافظه یا Memory Leak نشوند و اگر مشکلی بود بهتر هست که به صورت دستی مدیریت حافظه صورت بگیرد.

در ابتدا IBM کامپیوتر های بزرگی در اختیار شرکت ها میگذاشت که Task Oriented بودند و فقط یک Batch script دریافت میکردند و خط به خط اون هارو اجرا میکردن.
اما در هنگام اجرای یک برنامه کاره دیگری از این سیستم نمیتوانستیم بخواهیم. و از تمام توان سخت افزار استفاده نمیشد.

به همین خاطر مفهوم مجازی سازی به وجود آمد تا بتوانیم از تمام توان کامپیوتر ها استفاده کنیم.
در این حالت یک برنامه به Main Fraim کامپیوتر داده میشد تا با ایجاد چند Main Frame مجازی استفاده از سخت افزار را به نهایت میرساند.
با آمدن Unix بتوانستیم چند پروسس را همزمان اجرا کنیم.
اما مشکل اینجا بود که ما سیستم های سخت افزاری متفاوتی داریم که Unix باید برای همه آنها کامپایلر مخصوص ارائه دهد.
جلوتر JVM به وجود آمد که زبانی مثل java به بایت کد های قابل فهم روی JVM معرفی شد و بعد به زبان سخت افزار مورد نظر کامپایل میکرد.
بعد از آن انقلاب VMware به وجود آمد که میتوانستیم روی سیستم ها چندین OS مجازی سازی کنیم.
جلوتر LXC یا لینوکس کانتیر ها بلد شد که جلوتر Docker آن را کامل کرد.

روش های مجازی سازی :
Virtualization Approach : 
در این سناریو یک ماشین کامل هم از نظر سخت افزاری و هم از نظر نرم افزاری شبیه سازی میکنیم.
در اینجا یک سیستم عامل میزبان داریم که همان Host هست که روی آن یک لایه روی آن Hyper Visor می آید که یک سیستم عامل را برای ما شبیه سازی میکند.
که دو مولفه مهم دارد. Virtual Machin monitor که وظیفه مدیریت کد هایی را دارد که فقط کرنل متوجه آن میشود. VMM
که لایه نرم افزاری را مدیریت میکند.
Device Model : وظیفه شبیه سازی سخت افزار را دارد.


Container Base : در این حالت فقط پروسس ها ایزوله میشوند. و برنامه ها نمیتوانند با هم در ارتباط باشند و به چیز دیگری دسترسی ندارد مگر اینکه خودمان بخواهیم در نتیجه از سخت افزار هیچ خبری ندارند.

Linux Container :
ما میخواهیم مجموعه از فعالیت هارا به صورت ایزوله روی کرنل خاصی اجرا کنیم.

لینوکس یک امکانی به اسم Namespace دارد که میتواند کرنل را دسته بندی کند که برای ایزوله کردن و کنترل کردن کانتینر ها کمک میکند.
که هرکدام از این پروسس ها به یک Namespace ها دسترسی دارند.
cgroups کمک میکنند تا الویت بندی در Allocation داشته باشیم.
Layered File System میتوانیم لایه هایی را در دیسک Share کنیم که حافظه کمتری مصرف کنیم.
در نهایت با تمام این ویژگی ها یک Container runtime داریم.

کلاس ویژه ای هست که میتواند داخل هر کلاسی باشد.
و همنام با کلاس هست.
زمانی که یک نمونه از کلاس ساخته میشود به صورت اتوماتیک این متد صدا زده میشود.

5 مدل مختلف دارد:
1- Default Constructor : مقدار ورودی ندارد

2- Parametrized Constructor :  مقدار ورودی دارد

3- Copy Constructor : با ایجاد یک نمونه از کلاس و پاس دادن آن به کانستراکتوری که ورودی آن همان کلاس هست یک کپی از شی قبلی با نام جدید ایجاد میشود.

4- Static Constructor :  با کلمه کلیدی static مشخص میشود و زمانی فراخوانی میشود که متد های static های داخل کلاس را صدا بزنیم. که قبل از متدی که صدا زده شده اجرا میشود.

5- Private Constructor : با کلمه کلیدی private مشخص میشود و کسی نمیتواند دیگر از کلاس نمونه سازی کند. زمانی از آن استفاده میکنیم که مطمئنیم تمام متد های کلاس static هستند.

6- Primary Constructor
در کلاس این نوع کانستراکتور از کلمه this نمیتوان استفاده کرد چرا که نمیدانیم بعد کامپایل به چی تبدیل میشود.

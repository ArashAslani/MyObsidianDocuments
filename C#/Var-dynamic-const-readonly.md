const vs readonly : یک متغیر readonly هم میتواند زمان تعریف مقدار دهی شود هم در کانستراکتور و حتی میتواند مقدار نداشته باشد.
اما const زمان تعریف باید مقدار دهی شود.
readonly متغیر run time است ولی const از نوع compile هست.

var vs dynamic :  متغیر var یک متغیر compile time هست و به اصطلاح به آن Anonymous variable هم میگویند. 
اما dynamic متغیری runtime هست و نوع و مقدار آن اخرین تایپ و مقداری هست که میگیرد.
